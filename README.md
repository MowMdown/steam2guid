# steam2guid

Precomputed BattlEye GUID → SteamID64 lookup tables for DayZ server tools. Hashes every Steam account once so any GUID resolves in microseconds, with signed tables you can share and verify.

A shorter one, if you want it to fit on one line:

Turn BattlEye GUIDs back into SteamIDs with precomputed, signed lookup tables.
